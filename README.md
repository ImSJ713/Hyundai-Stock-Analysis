# 🚗 현대차(005380.KS) 주가 데이터 분석 및 머신러닝 예측 프로젝트

파이썬(Python)과 머신러닝을 활용하여 현대자동차의 과거 주가 데이터를 수집·정제하고, 기술적 지표를 기반으로 한 주가 방향(상승/하락) 예측 모델을 구현한 개인 미니 프로젝트입니다.

---

## 📌 1. 프로젝트 개요
- **목적:** 주식 시계열 데이터를 직접 다루어보며 데이터 전처리, 피처 엔지니어링, 그리고 머신러닝 모델링 역량 배양
- **개발 환경:** Google Colab, Python
- **사용 라이브러리:** `yfinance`, `pandas`, `numpy`, `matplotlib`, `scikit-learn`

---

## 🔍 2. 주요 기능 및 수행 과정
1. **데이터 수집 및 정제:**
   - `yfinance` 라이브러리를 활용해 현대차(`005380.KS`)의 시계열 주가 데이터(Open, High, Low, Close) 수집
2. **기술적 지표 (Feature Engineering) 추가:**
   - **이동평균선 (MA20, MA60):** 단기 및 중기 주가 추세 파악
   - **이동평균 괴리율 (Disparity_20):** 현재 주가와 20일 이동평균선 간의 격차 계산
   - **RSI (Relative Strength Index):** 주가의 과매수/과매도 상태를 나타내는 상대강도지수 산출
3. **머신러닝 모델 학습 및 예측:**
   - **분류 모델:** `RandomForestClassifier` 활용
   - **타겟(Target) 정의:** 익일 종가가 당일 종가보다 높으면 1(상승), 낮으면 0(하락)으로 설정
   - **성능 개선:** 기본 가격 및 이동평균선만 사용했을 때 대비 기술적 지표(RSI, 괴리율)를 추가하여 예측 정확도를 개선함 (정확도 약 46.48%)

---

## 📈 3. 프로젝트를 통해 배운 점
- 주식 시장의 높은 노이즈와 무작위성으로 인해 단순 머신러닝 모델로 고정밀 예측을 하는 것의 한계를 이해하고, 이를 보완하기 위한 피처 엔지니어링(기술적 지표 추가)의 중요성을 체감했습니다.
- 데이터 수집부터 전처리, 모델 학습 및 평가까지 이어지는 **머신러닝 파이프라인(Pipeline)** 전체를 직접 구축해 보며 실무 데이터 분석에 대한 자신감을 얻었습니다.
